# Исходный код проекта

В этой папке размещается **основной код проекта**, который используется для:

- подготовки данных;
- обучения моделей;
- инференса (получения предсказаний);
- запуска сервисов (API/CLI/скриптов).

Организация кода:

- `src/service/` - запуск сервиса (FastAPI);
- `src/evaluation.py` - обучение и вычисление метрик;
- `src/logger.py` - логирование сервиса;
- `src/predict.py` - предсказание спроса;
- `src/preprocessing.py/` - предобработка датасета для обучения;
- `src/splitting.py/` - разбиение датасета на train и test с учетом временного характера данных;
- `src/utils.py/` - вспомогательные функции.



Опишите основные команды запуска в файле `project/README.md`.
