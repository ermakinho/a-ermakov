# Итоговый проект по курсу «Инженерия Искусственного Интеллекта»

В этой папке находится итоговый мини-проект по курсу.  
Проект должен демонстрировать применение методов и инструментов инженерии ИИ: работу с данными, модели, пайплайны, сервис, эксперименты и (по возможности) воспроизводимость.



---

## 1. Паспорт проекта

- **Название проекта:** `Сервис прогнозирования спроса на аренду велосипедов`
- **Автор:** `Ермаков Андрей Евгеньевич`
- **Группа:** `КСБО-13-24`
- **Контакт:** `@lauendewrau`

- **Краткое описание (2-4 предложения):**  
  Проект посвящён построению сервиса прогнозирования почасового спроса на аренду велосипедов на основе исторических данных.  
  Используются открытый датасет Bike Sharing Demand с Kaggle, модели регрессии и baseline-модели на контентных признаках.  
  Результат – REST API на базе FastAPI, который принимает параметры времени, погодных условий и календарных признаков и возвращает прогнозируемое количество аренд велосипедов за указанный час.


---

## 2. Структура проекта

Проект организован в следующей структуре:

- `requirements.txt` – зависимости проекта (библиотеки Python, необходимые для запуска).
- `report.md` – отчёт по проекту (постановка задачи, данные, эксперименты, результаты).
- `self-checklist.md` – чеклист самопроверки проекта перед сдачей.
- `notebooks/` – экспериментальные ноутбуки:
  - EDA, выделение признаков и предобработка.
  - Эксперименты: сравнение нескольких моделей, легкий подбор гиперпараметров для выявления самой перспективной модели.
  - Подбор гиперпараметров, выявление лучшей модели, ее переобучение на всех данных и сохранение.
- `src/` – основной код проекта:
  - `service/` — запуск сервиса (FastAPI);
  - `evaluation.py` - обучение и вычисление метрик;
  - `logger.py` - логирование сервиса;
  - `predict.py` - предсказание спроса;
  - `preprocessing.py/` - предобработка датасета для обучения;
  - `splitting.py/` - разбиение датасета на train и test с учетом временного характера данных;
  - `utils.py/` - вспомогательные функции.
- `data/` – демонстрационные/учебные данные:
  - `raw/train.csv` - учебный датасет Bike Sharing Demand, взятый с Kaggle (весит 600 Kb)
- `configs/` – конфигурационные файлы:
- `tests/` – тесты (юнит-тесты, простые проверки).
- `artifacts/` – сохранённые модели, отчёты, результаты экспериментов.

## 3. Требования и установка

### 3.1. Требования

- Python `>= 3.11`

### 3.2. Установка окружения

Примерный сценарий (можно адаптировать под ваш проект):

```bash
# Перейти в папку проекта
cd project

pip install uv

uv venv

# Windows:
.venv\Scripts\activate
# Linux / macOS:
source .venv/bin/activate

uv sync
```

## 4. Как запустить проект


### 4.1. Запуск сервиса (API/веб-интерфейс)

```bash
cd project
uv run uvicorn src.service.app:app
```


- Сервис поднимается на порту 8000;
- Основной эндпоинт `/predict`, также есть `/health`;
- Чтобы протестировать работоспособность сервиса, запустите его → перейдите на Swagger UI: `http://127.0.0.1:8000/docs` → `/predict` → Try it out → Execute.
