# Ноутбуки проекта

В эту папку помещаются **экспериментальные ноутбуки**:

- разведочный анализ данных (EDA);
- прототипы моделей;
- отдельные эксперименты;
- разовые проверки гипотез.

Рекомендуется:

- давать ноутбукам осмысленные имена, например:
  - `exp01_eda_baseline.ipynb`
  - `exp02_model_tuning.ipynb`
- по возможности добавлять краткое текстовое описание в начале ноутбука:
  - цель эксперимента;
  - какие данные используются;
  - какие основные выводы.

Всё, что становится «боевым» кодом (препроцессинг, обучение, инференс), по возможности выносите в модульный код в папку `src/`.

1. Ноутбук с разведочным анализом данных, предобработкой данных и конструированием новых признаков.
2. Ноутбук с экспериментами, в ходе которых осуществлялось сравнение моделей и выбор лучшей.
3. Ноутбук с подбором гиперпараметров LigthGBM и сравнением полученной модели с лучшей моделью экспериментов. После выбора лучшей модели, сразу же было произведено ее переобучение на всем датасете и ее сохранение.
